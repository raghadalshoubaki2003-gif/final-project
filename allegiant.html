01 / THE WEAKNESS

INPUT BINDING
Mass assignment occurs when an application binds submitted fields to an object without restricting which properties a caller may change. A user-editable display name must not silently grant control over clearance or other privileged attributes.

04 / SECURITY FIX

EXPLICIT FIELD ALLOWLIST
01async function updateProfile(req, db) {02 const citizen = await db.find(req.user.id);03 if (!citizen) throw new Error('Not found');04 const { displayName } = req.body;05 const allowed = { displayName };06 Object.assign(citizen, allowed);07 await db.save(citizen);08 return citizen;09}
Lines 04–06: copy only the field the user may change; sensitive properties are never bound from request data.

IMPACT / WHY IT MATTERS

Depending on the application, uncontrolled fields can let a user alter roles, ownership, approval status, or other sensitive data. Use dedicated input objects or explicit allowlists. Field filtering complements—not replaces—authorization.

FIELD NOTES

The fixed mode still accepts the ordinary display-name update. It ignores or rejects the same privileged-field payloads.
